Formatting and JSON reference

Write sections as continuous lines: Enter creates a paragraph, Shift+Enter adds a soft line break, and Tab / Shift+Tab adjusts the current line’s indent. Each line keeps its own styling; use its ⋯ menu for settings. Names and pronouns are ordinary editable text in the visual editor. The JSON automatically stores the corresponding character tokens. Pasting converts the current character’s name and gendered pronouns to tokens automatically; neutral and plural pronouns stay as written.

Bracketed terms such as [Water] and [Freeze] automatically receive their matching font-color classes from mlg.css. Select text in a paragraph to apply a custom color or text class. Type [dmg1] for a dynamic value or [dmg1%] to include a percentage. Existing value keys such as [heal%] work too. Set each base value in Level scaling & advanced settings. Keep durations and cooldowns as ordinary text. Small metadata uses the same plain formatting as the skill viewer.

Effect descriptions use {{effect:freeze}}. Inline names use <b class="freeze">[Freeze]</b>. Character tokens can refer to another ID, for example {{nickname:c2}}. A star level starts a new group in Dupes, and the following paragraphs continue that group until the next numbered entry.

Open the images/mlg-assets/Characters folder once to save directly. The editor remembers it for future visits, so use Save JSON for later changes. You can also copy/download the JSON into the displayed file. Local drafts are kept per character file in this browser. Changes to the skill list in data-character.json are made separately.
